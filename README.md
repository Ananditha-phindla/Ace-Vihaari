# 🎓 AceVihaari – Academic Communication Web Platform

AceVihaari is a **web-based academic management system** designed to act as a communication bridge between **students and faculty**.  
It offers **role-based dashboards**, **notifications**, **secure authentication**, and **performance analytics** to streamline academic interactions.

---

## 🚀 Live Demo

🔗 **Project URL:**  
👉 https://acevihaari.vercel.app/

> ⚠️ **Note:**  
This project uses **role-based authentication**. To explore the application, please log in using the demo credentials provided below.

---

## 👥 User Roles

### 👨‍🏫 Faculty (Teacher)
- Compose notifications for targeted students (branch & section wise)
- Upload notes in multiple formats (PDF, DOC, PPT, etc.)
- View student performance leaderboard
- Manage profile and account settings

### 👨‍🎓 Student
- View leaderboard based on CGPA, attendance and coding profiles
- Access faculty-uploaded notes
- Receive notifications
- Analyze performance through dashboard charts
- Manage profile and account settings

## 🛠️ Tech Stack

### Frontend
- React.js (Vite)
- Tailwind CSS
- Axios
- React Context API

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MySQL

### Authentication & Security
- Custom Authentication System
- Hashed Passwords
- JWT-based authentication
- HTTP-only cookies

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: TiDB
- Version Control: GitHub

---

## ✨ Key Features

- Role-based access control (Student & Faculty)
- Secure authentication with server-side session validation
- Academic and coding performance leaderboard
- Optimized backend queries for improved performance
- Scalable and modular architecture
